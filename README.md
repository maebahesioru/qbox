# QBOX - Xの質問箱サービス

Xで質問を集めるQ&Aサービス（マシュマロ/Peing + Yahoo知恵袋風）。**未ログイン・匿名で誰でも質問・回答できる**のが特徴。

## 機能

- **未ログイン・匿名で投稿**: 質問も回答もログイン不要。ニックネームは任意（空欄=匿名）
- **アカウントはMullvad方式**: ログインするなら16桁の番号がそのままID兼パスワード（メール/パスワード不要）
- **質問タイプ**
  - 個別質問（direct）: 特定の1人に質問
  - 複数人質問（multi）: 複数人に同じ質問、それぞれ回答
  - 全体質問（all）: 全員への質問（ホームのフィード）
- **Q&A(知恵袋風)**: 複数人が回答 → 質問者が納得したら**ベストアンサー**を選んで解決
  - ベストアンサーは質問時に発行される**質問管理トークン**で選定（ブラウザに自動保存）
- **X連携は各自で投稿**: bot自動投稿は使わない。「この質問をポスト」「この回答をポスト」ボタンで **Xのシェア画面(intent/tweet)を開き、自分のXアカウントでURLを貼って投稿**する
- **OGP疑似画像**: 質問/回答に画像を添付すると、Xでリンクを貼った時に **OGP画像としてプレビュー表示** される（URL投稿でも画像が添付されているように見える）

## 技術スタック

- Next.js 16 / React 19 / TypeScript / Tailwind CSS 4 / pnpm
- JSONファイルストア（`data/*.json`、DB不要）
- X投稿は各自のアカウントで行うため、外部API連携・botは不要

## 環境変数

- `SITE_URL`: サイトの絶対URL（OGP生成用。本番は `https://...`）

## 開発

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm build && pnpm start -p 3100
```

## デプロイ

- Coolify: Dockerfile同梱（standaloneビルド）。`data/` ディレクトリは永続ボリュームにマウントしてください（アカウント・質問・アップロード画像が消えます）
